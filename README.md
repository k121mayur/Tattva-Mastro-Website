## 🚀 Quick Start / Preview

### Option 1: Open directly in any browser
Double-click [`index.html`](index.html) to open it directly in Chrome, Edge, Safari, or Firefox.

### Option 2: Run a local HTTP server
Using Node.js:
```bash
npx serve .
```

Or using Python:
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`
